# NHTSA recall 24V853000: Power Train:Axle Assembly

| Field | Value |
|---|---|
| Campaign | 24V853000 |
| Report received | 2024-11-08 |
| Manufacturer | Diamond C Trailer MFG |
| Component | POWER TRAIN:AXLE ASSEMBLY |
| Potential units affected | 1432 |
| Recall initiated by | MFR |

## Vehicles

DIAMOND C TRAILERS MFG 2023, DIAMOND C TRAILERS MFG 2024, DIAMOND C TRAILERS PACESETTER 2023, DIAMOND C TRAILERS PACESETTER 2024

## Defect

Diamond C Trailer MFG (Diamond C) is recalling certain 2023-2024 MFG and Pacesetter trailers.  Please see the recall report for a complete list of models.  The weld between the axle frame bracket assembly and frame may fail, reducing the trailer's stability while being towed.

## Consequence

Instability can increase the risk of a crash.

## Remedy

Dealers will install a locking flange nut to the torsion hanger frame, free of charge.  Owner notification letters were mailed January 15, 2025.  Owners may contact Diamond C customer service at 1-903-572-2834.
